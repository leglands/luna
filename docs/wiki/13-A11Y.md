## LUNA-Specific Accessibility Features

### Calm Mode

| Aspect | Detail |
|--------|--------|
| **Purpose** | Reduces anxiety by hiding prediction-related content (next period, fertile window, ovulation) |
| **Activation** | Settings → Toggle "Calm Mode" (`UserDefaults` key: `calm_mode`) |
| **Effect** | Hides: prediction cards, fertile window on calendar, ovulation markers. Shows: `CalmModeBanner` explaining why content is hidden |
| **a11y** | Banner is announced on screen reader. Hidden components removed from accessibility tree |

### Reduce Motion

| Aspect | Detail |
|--------|--------|
| **Detection** | `@Environment(\.accessibilityReduceMotion)` (iOS) / `Settings.Global.ANIMATOR_DURATION_SCALE` (Android) |
| **Effect** | Disables spring animations, crossfade transitions, donut chart animation. Uses instant transitions instead |
| **Scope** | All animated components respect this setting |

### Zero Emoji Policy

| Aspect | Detail |
|--------|--------|
| **Rationale** | Emoji are ambiguous across platforms, poorly announced by screen readers, and culturally inconsistent |
| **Mood Picker** | Numeric circles (1-5) with text labels instead of emoji faces |
| **Icons** | SF Symbols (iOS) / Material Icons + SVG Feather (Android) |
| **Screen Reader** | All icons have explicit `accessibilityLabel` — no reliance on emoji Unicode names |

### Accessibility Announcements

| Event | Announcement | Platform API |
|-------|-------------|-------------|
| Log saved | "Log saved for [date]" | `UIAccessibility.post(.announcement)` / `announceForAccessibility()` |
| Panic wipe started | "All data will be erased" | Alert dialog with confirmation |
| Cycle started | "New cycle started" | Post-action announcement |
| PIN error | "Incorrect PIN, [N] attempts remaining" | Inline error + announcement |
| Calm Mode toggled | "Calm Mode [enabled/disabled]" | Toggle state change |
